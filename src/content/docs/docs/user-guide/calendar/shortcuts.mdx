**What you'll learn:** the keyboard shortcuts in Calendar and how to turn them on or off.

Press `?` in Calendar to see the shortcuts for the screen you're on. Turn single-key shortcuts on or off in
**Settings → General → Keyboard shortcuts**. They're also off while the full event editor is open, which has
its own keys.

On a Mac, `Ctrl` in these tables means `⌘`.

## General

| Keys | Action |
|---|---|
| `Ctrl+K` | Command palette |
| `?` | Keyboard shortcuts |
| `Ctrl+B` or `[` | Collapse or expand the sidebar |
| `/` | Search events |

## Navigation

| Keys | Action |
|---|---|
| `t` | Today |
| `j` or `n` | Next period |
| `k` or `p` | Previous period |
| `g` | Go to date |

## Views

| Keys | Action |
|---|---|
| `d` | Day view |
| `x` | 4-day view |
| `w` | Week view |
| `m` | Month view |
| `a` | Schedule view |
| `y` | Year view |

## Events

| Keys | Action |
|---|---|
| `c` | Create event |
| `e` | Edit selected event |
| `Delete` or `Backspace` | Delete selected event |
| `Esc` | Close the open popover, or clear the selection |
| `Esc` while dragging | Cancel the move or resize |

## Event editor

| Keys | Action |
|---|---|
| `Ctrl+Enter` or `Ctrl+S` | Save event |
| `Esc` | Close editor |

## Quick create

| Keys | Action |
|---|---|
| `Enter` | Save |
