**What you'll learn:** the keyboard shortcuts in Mail and how to turn them on or off.

Mail's shortcuts follow Gmail's. Press `?` in the app to see the list for the screen you're on.
Turn single-key shortcuts on or off in **Settings → General → Keyboard shortcuts**.

On a Mac, `Ctrl` in this table means `⌘`.

## General

| Keys | Action |
|---|---|
| `Ctrl+K` | Command palette |
| `?` | Keyboard shortcuts |
| `Ctrl+B` or `[` | Collapse or expand the sidebar |
| `/` | Search mail |
| `c` | Compose |

## Go to

| Keys | Action |
|---|---|
| `g` then `i` | Inbox |
| `g` then `s` | Starred |
| `g` then `t` | Sent |
| `g` then `d` | Drafts |

## Conversation list

| Keys | Action |
|---|---|
| `j` | Next (older) conversation |
| `k` | Previous (newer) conversation |
| `o` or `Enter` | Open conversation |
| `u` | Back to the list |
| `↑` / `↓` | Move the cursor on a focused row |
| `x` or `Space` | Select conversation |
| `Esc` | Clear selection |
| `e` | Archive |
| `#` | Delete |
| `!` | Report spam |
| `s` | Star or unstar |
| `Shift+I` | Mark as read |
| `Shift+U` | Mark as unread |
| `l` | Label as… |
| `v` | Move to… |
| `m` | Mute (not supported by the server yet) |
| `z` | Undo last action |

Actions apply to the selected conversations, or to the open or highlighted one when nothing is selected.

## Reading a conversation

| Keys | Action |
|---|---|
| `r` | Reply |
| `a` | Reply all |
| `f` | Forward |
| `n` | Next message in the conversation |
| `p` | Previous message in the conversation |

## Compose

| Keys | Action |
|---|---|
| `Ctrl+Enter` | Send |
| `Enter`, `Tab`, `,` or `;` | Turn typed text into a recipient chip |
| `Esc` | Leave full screen |

## Label picker

| Keys | Action |
|---|---|
| `Space` | Toggle a label |
| `Ctrl+Enter` | Apply |

<Aside type="note" title="Shortcuts in text fields">
Single-key shortcuts don't fire while you type in a text field. `Ctrl+K` works everywhere.
</Aside>
